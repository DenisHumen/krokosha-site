## Как дизайн перенесён в `web/`

- **Страницы.** `pages/*.dc.html` — превью на шаблонизаторе `support.js` с React-логикой. На сайте это статический HTML Astro: разметка и классы каждой секции — в `web/src/components/*.astro`, инлайн-стили стали scoped CSS (CSP сайта не пускает `style="…"`), значения, которые превью вычисляло в `renderVals()`, считаются при сборке или в CSS (`@media`, `:has()`, `aria-expanded`, `[open]`).
- **Поведение** — небольшие модули без библиотек: `web/src/scripts/home.ts` (прокрутка ведёт руки, заголовок, точку рамки, параллакс занавеса и подчёркивание меню; руки и пасхалки загружаются после `load`), `web/src/scripts/skills.ts` (стойки, поиск, линии с пакетами — длина линии по `getTotalLength()`), игра на 404 — в `pages/[...lang]/404.astro`.
- **`hands.js` и `eggs.js`** импортируются прямо из `design/` (через `web/src/scripts/hands.ts` и динамический импорт) — правки дизайнера в этих файлах попадают на сайт при следующей сборке.
- **Без JavaScript** всё читается: стойки навыков раскрыты (свёрнутый вид — только при `<html class="js">`, класс ставит `public/assets/theme.js`), «Все репозитории» — нативный `<details>`, меню на телефоне — `popover` (открывается без скрипта), форма работает обычным POST.
- **Семантика**, которую превью не задавало: подписи секций («Что я делаю», «В цифрах») — `<h2>` в виде подписи, уровни заголовков идут по порядку; у цифр статистики `<dt>` раньше `<dd>` (порядок на экране задаёт CSS), число есть текстом для экранного диктора; дерево навыков — список с кнопками-раскрывашками (`aria-expanded`, закрытая стойка `inert`) вместо `role="tree"` без клавиатурной навигации.
- **Шрифты** Geologica и Fira Code — из пакетов Fontsource в `node_modules` через Fonts API Astro (`astro.config.ts`): никаких запросов к Google, метрически подогнанный запасной шрифт — текст не прыгает, когда шрифт приходит.

### Отличия от превью, сделанные сознательно

- Нижние подписи первого экрана на телефоне подняты над плавающей панелью (в превью панель их закрывала); на экранах уже 600 px средняя подпись идёт первой строкой.
- «[Scroll to explore]» мигает два раза и замирает, а не бесконечно: мигающий текст дольше 5 секунд нарушает WCAG 2.2.2.
- Кольцо занавеса на телефоне — то же кольцо в половинном масштабе (в превью внутренние кольца на телефоне сдвигались на фиксированные 26/52 px).
- Карточки проектов не показывают `topics` и ссылку `homepage` — как в превью; вся карточка — ссылка на репозиторий.
- Тексты, которые превью держало в коде, перенесены в контент (`content/site.yaml` → `site.json`, контракт v1.5). Технические подписи в духе сетевой консоли — «ACK · 201 CREATED», «404 · ICMP TIME EXCEEDED», «POST /api/leads · no cookies», «/PLAY · LEVEL 0», «eggs 2/8», «github · 23» — остались в разметке и одинаковы на всех языках.

## Админка

`api/internal/admin/static/achievement.js` — копия `design/components/eggs/achievement.js` для страницы «Ачивки» (проверка уведомлений): тест `TestTheBenchShowsTheSitesBanner` требует, чтобы файлы совпадали байт в байт — после правки баннера в `design/` его нужно скопировать и туда.

`api/internal/admin/static/admin.css` = `design/admin/admin.css` с двумя отличиями: шрифты раздаёт сама админка (`static/fonts/`, латиница и кириллица, OFL) вместо `@import` с Google — CSP админки его не пропускает, а визиты владельца не должны уходить третьей стороне; и `.inline .button { width: auto }` — кнопка «Подставить» рядом с выбором шаблона отказа растягивалась на всю ширину (ошибка была и в прежнем CSS).
