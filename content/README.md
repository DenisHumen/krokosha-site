# content/ — редактируемые данные сайта

Всё, что видно на сайте, хранится здесь, а не в разметке. Денис правит YAML — сайт пересобирается сам (таймер каждые 6 ч или кнопка «пересобрать» в админке).

```
content/
├── site.yaml         профиль, career_start (стаж), соцсети, направления услуг, тексты-подписи, флаги (пасхалки, форма, реклама)
├── skills.yaml       дерево навыков: категория → группа → навык
├── projects.yaml     закреплённые / скрытые репозитории, ручные правки, приватные (NDA) проекты
├── pages/            длинные тексты страниц по языкам: privacy.en.md, privacy.uk.md, privacy.ru.md
├── schemas/          JSON Schema для проверки YAML в CI (фаза 1)
└── generated/        результат GitHub sync — не редактировать, в .gitignore
```

## Соглашения

- `TODO(Денис)` — значение нужно заполнить или подтвердить. Пока оно стоит, на сайте показывается безопасный плейсхолдер или элемент скрывается.
- `confirmed: false` у навыка — позиция добавлена как типичная и ждёт подтверждения. На сайте не показывается, пока в `site.yaml` не включено `skills.show_unconfirmed`.
- **Языки:** `en` (основной, адрес `/`), `uk` (`/uk/`), `ru` (`/ru/`). Текстовое поле — либо строка (одинаково на всех языках: `MikroTik`, `GitHub`), либо словарь `{ en: …, uk: …, ru: … }` — заполнять все три.
- **Множественное число** — формы в `site.yaml → plurals` (`en: [one, other]`, `uk`/`ru`: `[one, few, many]`), в текстах — плейсхолдер `{years}`: сборка сама напишет «1 рік / 2 роки / 8 років».
- **Плейсхолдеры** `{id}`, `{hours}`, `{email}`, `{privacy_link}`, `{year}` подставляет сборка — не удалять.
