# mock/ — данные в формате контракта

Файлы для дизайна (превью в `design/preview/`) и для тестов. Формат описан в [`docs/contract.md`](../docs/contract.md). Сборка сайта потом получает данные ровно такой же формы из `content/` + GitHub sync.

Разложены по языкам — `en/` (основной), `uk/`, `ru/`. В каждой папке одни и те же файлы одной формы, строки уже переведены, множественное число подставлено:

| Файл | Что внутри | Откуда |
|---|---|---|
| `<lang>/profile.json` | имя, роль, стаж, аватар, соцсети | `content/site.yaml` |
| `<lang>/skills.json` | дерево навыков (3 уровня) | `content/skills.yaml` |
| `<lang>/projects.json` | публичные репозитории с `tier` + приватные проекты | снимок GitHub `DenisHumen` на 2026-09-18 + `content/projects.yaml` |
| `<lang>/site.json` | все тексты страницы, языки, флаги | `content/site.yaml` |
