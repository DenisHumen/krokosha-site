# design/ — зона Claude Design

Сюда складывается всё, что делает дизайн. Бэкенд эту папку **не переписывает**: интеграция идёт через тонкие обёртки в `web/src/components/`. Если для подстановки данных пришлось минимально изменить разметку здесь, изменение описывается в [`docs/integration-notes.md`](../docs/integration-notes.md).

Бриф для дизайна: [`docs/design/CLAUDE_DESIGN_PROMPT.md`](../docs/design/CLAUDE_DESIGN_PROMPT.md).

## Структура

```
design/
├── tokens.css              ← ОБЯЗАТЕЛЬНО: все дизайн-токены обеих тем (создаёт дизайн)
├── components/             один компонент = одна папка: <name>.html|.tsx + <name>.css + <name>.js (если нужен) + README.md
│   ├── layout/             верхняя навигация, левая рамка соцсетей, нижняя панель (mobile), футер, переключатель темы
│   ├── hero/               руки из символов (canvas/WebGL), заголовок, CTA, нижние подписи
│   ├── services/           «Что я делаю»: липкие выталкивающие номера 01–05
│   ├── skills/             дерево навыков: узел → линии → пилюли, поиск
│   ├── projects/           карточки репозиториев (featured / standard / compact), карточка приватного проекта, заметка
│   ├── stats/              dot-matrix цифры (стаж, число проектов)
│   ├── curtain/            тёмная панель-занавес с параллаксом
│   ├── contacts/           кнопки быстрой связи + форма «Обсудить проект» со всеми состояниями
│   ├── eggs/               пасхалки: крокодил, кот, konami, sudo-терминал, reboot аватара, 404-игра, ачивки
│   └── ui/                 базовые: кнопка-пилюля, метка, поле ввода, иконка, ссылка
├── pages/                  сборка страниц из компонентов: index, 404, privacy, thanks (успех формы без JS), play (заглушка)
├── admin/                  (опционально) экраны админки по ref-03
├── email/                  (опционально) HTML-письма: автоответ клиенту, уведомление о заявке
├── assets/
│   ├── fonts/              только открытые лицензии, с кириллицей (woff2)
│   ├── icons/              SVG-иконки (соцсети, категории навыков)
│   ├── svg/                декоративная графика, фолбэк рук
│   ├── images/             растровые изображения (AVIF/WebP + исходник)
│   ├── lottie/             персонажи (.json)
│   ├── rive/               персонажи (.riv)
│   └── hands/              исходники рук: карта глубины / облако точек + скрипт генерации
├── preview/                standalone-страницы на мок-данных (fetch ../../mock/<lang>/*.json, ?lang=en|uk|ru; открывать через `npx serve .` из корня)
└── handoff/                спецификации: анимации (тайминги, кривые), состояния, адаптив, CHANGELOG.md
```

## Правила

1. Данные — только из [`mock/`](../mock/) по контракту [`docs/contract.md`](../docs/contract.md). Своих структур не придумывать. Сайт на трёх языках (EN основной, UA, RU): ни одного захардкоженного текста.
2. Место подстановки данных помечается `data-slot="…"`. Отслеживаемые элементы — `data-track="…"`, секции — `data-section="…"`.
3. Повторяющийся элемент (карточка, узел навыка, кнопка соцсети) сдаётся **одним шаблонным компонентом**, а не N копиями.
4. Никаких платных зависимостей и растровых GIF. Шрифты — Google Fonts / Fontsource с кириллицей.
5. Изменения вносятся через PR; в описании PR — что поменялось и почему, скриншоты светлой и тёмной тем.
