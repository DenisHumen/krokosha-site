# api/ — Go API и CLI

Один бинарник под systemd (`krokosha-api.service`) на `127.0.0.1:8080`, за Nginx. Go-модуль с корнем в этой папке.

Статус: код появится в фазе 1.

```
api/
├── cmd/
│   ├── krokosha-api/     точка входа сервиса
│   └── krokosha-cli/     CLI: создание админа, invite-коды бота, пересборка, удаление данных
├── internal/
│   ├── config/           чтение /etc/krokosha/env
│   ├── db/               SQLite (WAL), миграции, репозитории
│   ├── auth/             argon2id, сессии, CSRF, TOTP
│   ├── analytics/        приём /api/e, валидация, дневная соль, агрегаты
│   ├── admin/            HTTP-хендлеры админки, SSE-лента активности, экспорт CSV
│   ├── githubsync/       синхронизация репозиториев, ранжирование (tier), аватар, запуск сборки
│   ├── profile/          стаж от career_start (unit-тесты на граничные даты)
│   ├── leads/            форма заявок: антиспам, ALTCHA, статусы, аудит
│   ├── outbox/           надёжная доставка уведомлений с ретраями
│   ├── telegram/         бот: приглашения, роли, карточки, ретрансляция клиентов
│   ├── mail/             SMTP-отправка с DKIM, IMAP IDLE для ответов клиентов
│   ├── nginxlog/         инкрементальное чтение JSON access-лога Nginx
│   ├── sysstatus/        сертификаты, диск/RAM/нагрузка, статус почты
│   └── game/             зарезервировано под мини-игру (часть D, не реализуется)
├── migrations/           SQL-миграции
└── web/admin/            шаблоны и статика админки
```
